# 水晶计算实机回归

独立测试模组，不进入发行客户端。使用真正的 Minecraft 1.21.11 客户端和原版集成服，复制测试世界后运行；不修改原存档。

```powershell
tools/crystal-probe/run-probe.ps1 -Name candidate-final -WorldPath 'C:\test-world' -JavaHome 'C:\jdk-21'
```

测试内容：

- 无遮挡、石墙、黑曜石墙、半砖、护甲、移除遮挡六组真实水晶爆炸，比较客户端预测和服务器生命扣减，允许浮点误差 0.02。
- 同时记录保留的 Rusher 遮挡算法作几何对照，不能把它当作两套完整客户端的对战结果。
- 高速自动自伤预测、沿途风险、薄墙碰撞及 Rusher 的零自预测行为。
- 向异步排序器注入过期低伤害提示，验证 DEFAULT 仍释放旧点锁并保持当前伤害上界排序。
- 用服务器拥有的僵尸提供测试目标缓存，调用模块真实选点、放置、选晶、攻击路径，确认实际网络动作造成服务器扣血。生产的玩家专用目标过滤保持不变；这个环节不代表完整玩家对战自动寻敌或胜率测试。

结果写入仓库同级 `crystal-v2-lab/<Name>/`，包括 `damage.csv` 和 `complete.txt`；异常则写 `failure.txt`。`packet-chain` 行分别记录成功提交的放置数、攻击数、服务器扣血。客户端会自动退出。

启动先单独生成仅含测试夹具的 Jar，再使用项目既有的 `-PgzwDevelopmentBuild=true` 开发入口运行。开发客户端不能打包，授权、心跳、水印和生产保护均不修改。此测试不替代生产混淆包的授权及双 JDK 启动验收。

## 平地底座回归

给上述命令追加 `-FlatBase`，仅运行平地场景：双方同高、相距 6 格，脚下为实心草地，周围没有现成黑曜石。直接调用 DEFAULT 的真实底座选点及放置，再验证服务端确认黑曜石、放晶和攻击造成目标掉血。还检查原 Rusher 搜索行为、高伤害门槛及缩短放置距离后的拒绝结果。

夹具采用服务端僵尸作为目标，显式提供目标缓存，不覆盖玩家自动寻敌；驱动玩家使用创造模式与抗性 V 隔离自伤和击退。生产自伤、伤害、碰撞及授权检查均不修改。此场景用于复现搜索漏层及验证实际交互，不代表所有装备/设置下都应该放置。
