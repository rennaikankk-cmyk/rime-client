# SlimefunHelper 空战参考的取舍

本次根据 1.21.1-1.1.5.4-yclimb-default8 的静态复核吸收策略思路，不直接导入其反编译代码。

## 本轮增加

- 长矛撤离使用实际武器组件的剩余蓄力时间，过期时考虑停止使用与重新蓄力；没有固定写死 8 tick 或六种材质时长。
- 根据目标可信运动历史计算沿追击方向的速度。对手已经逃离时，若到达攻击范围前足够完成蓄力，则提前恢复追击，不再机械后退到固定超时。
- 未取得可信观测、目标急转/回拉、速度异常时保守回退。内圈避让、短暂撤离、最大恢复时限和已有地形/转头/武器控制权仍有效。
- 规则同时用于独立长矛模式和 MXS 内部长矛阶段。

## 已有更完整的实现

目标运动分类、连续威胁预测、碰撞约束、锤子下冲与命中确认、烟花与甲飞事务、逐轴飞行约束在当前代码中已有对应实现。保留现有实现，不照搬对方的平方距离错误、对手使用时间误读、时间小数截断或空预测函数。

## 1.21.1 移植边界

原生 1.21.11 使用 KineticWeapon/AttackRange 等组件。1.21.1 分支需独立适配 Via 映射长矛；只有显示名称或模型相似不足以授予攻击能力。协议桥的存在不代表实服已接受动作。普通 1.21.1 环境必须完整保留其他功能且安全降级不支持的长矛路径。

固定 action=7 原始包、TP 位移和通用 status=2 命中认定未经跨版本实服验证，本轮不把它们当作已验证的优化复制进新版。

验证入口：SpearRecoveryTest、SpearCombatTest、SpearApproachTest、ElytraCombatHookTest，以及完整构建与发布候选启动检查。以发行验收记录为准。
