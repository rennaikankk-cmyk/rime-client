# Grim 空战与默认交互调整（2026-09-22）

> 本文下方构建与启动记录对应 combat.6 / mc1211.6 / direct.11 历史候选。最新 combat.7 / mc1211.7 / direct.12 的防抖、协议限制和实测见 [空战防抖补全](air-combat-steering.md)，验收数据见 `air-combat-steering-acceptance.json`。

本轮是本地候选，尚未推送或发布。鞘翅飞行仅 Grim / NoAC。`AdaptiveSlowdown` 可关闭且默认关闭；关闭时仍清理回弹前的动作并短暂停止推进，不累计降速。

## 飞行和空战

- 重锤拉升在当前协议允许的包络内比较直向和四个斜向候选，评价向上速度及偏离截击路线的距离。方向至少保持六个 tick，碰撞可立即否决；接近顶点按当前上升速度提前回到精确路线。不会把 Via→1.20.4 的双视角测试速度套用到原生 1.21.11。
- 重锤可达性纳入最近两 tick 内实际应用的速度；已经取得高度且当前下落拦截可达时，不再因为完整往返估算失败而错过反击。最低规划高度还包含两 tick 脱离滑翔的距离、自然下落和姿态余量，不能为了缩短路径降到只有约三格。实际下落仍需通过换装、无障碍、预测命中及原版伤害条件。
- 长矛按武器组件读取自身速度和相对速度的伤害门槛，按攻击轴上的目标速度保留接敌速度；已蓄能时不再过早刹到伤害门槛以下。保留内圈撤离、射线、蓄能和碰撞约束，不将侧向总速度当成有效命中速度。
- 攻防换边需要持续证据，采用 tick 计时，碰撞可立即否决。未蓄能矛、空手和普通滑翔持锤不会仅因接近而打断进攻；观察到甲飞换装且向下接近的持锤目标，即便滑翔标志尚未更新，也进入威胁判断。
- 蓄能未完成的矛退出危险范围后匹配目标漂移；撤离结束立即更新追击向量。重锤连续两个不可达预测才因预测原因重启，实际危险和错过攻击平面仍立即处理。
- 开启 `AdaptiveSlowdown` 后，最近受控飞行关联的回弹使预算乘 0.7，最低 25%，连续回弹暂停 10/20/40/60 tick；稳定 100 tick 后每 20 tick 恢复 5%。不会扩大未知包络探速。关闭时不累计这些惩罚。
- 原生 1.21.11 自动重启滑翔同步释放/启动/按下跳跃的顺序，禁止相邻 tick 重复启动；库存换装暂时同步空输入后恢复，烟花使用在转头确定后、移动包之前提交。1.21.1 保留对应旧协议路径。
- 双视角不可用时，每次连接在聊天栏提示协议及单视角回退；无需 Via 仍可使用 Grim。重生不重复提示。
- 收起 16 个空战内部开关/常量。保留模式、范围、目标选择、自动接管、手动优先、武器选择、转头、重锤偏好高度/最低下落/自适应高度/普通补刀、矛接敌与撤离距离。武器选项按模式显示，退休配置不再覆盖内部策略。

## 其他模块默认交互

新建水晶配置默认原版范围（放置 4.5、攻击 3），默认不穿墙；锚默认 4.5、可见面、无凭空放置；活塞默认 4.5，等待对应转头并保留现有红石复用；Aura 保留 3 格、转头、原版冷却、关闭 TP/发包暴击。没有逐模块新增 Grim 开关，已有用户显式保存的参数不强制覆盖。锚、活塞、Aura 在回弹后暂停旧位置动作，水晶既有保护保留。这些默认值不等于所有服务器均不会报警。

## 并行和开销

沿用共享 1–2 个工作线程、有界队列和每任务仅保留最新输入的预测器。快照不持有可变世界、实体或背包；结果校验会话、目标、运动修订、阶段及最多两 tick 年龄。攻击、转头、换装和发包在主线程。重锤求根移除了临时数组和向量。斜向选择是主线程的小规模数值搜索并检查路径，尚未测出 FPS 收益。

## 实测与限制

本地 Fabric 1.21.11 + Grim 2.3.73，旧端原生 1.21.1 通过后端 ViaFabric 0.4.21+131、匹配的 ViaVersion 5.7.1-SNAPSHOT / ViaBackwards 5.7.0 连接。初始外部 ViaProxy 的 `grim-mace-a` 不作为有效比较；Grim 要求 ViaVersion 在后端。没有为旧端免除检查。

参考附件 SHA256：`1b70f13627d0c638a016b089e9d52c4a3b33c32ec1f920b9988ed95aa39c445c`；729 NBT SHA256：`d9eb60ef708057aea51c9ee1c11b55545777b51a69cb803f0d31f1bafd01088a`。真实导入 applied=1043、unknown=528；旧端 80 格高度和 1.7 重分配已生效，未知字段不算生效。双方生存、相同基础装备和消耗品，各两枚图腾；新端偏好高度 20，g/h 目标范围均为 150。对照的是旧端用户参数与新策略，不能当成相同策略仅更换某个公式的隔离实验。

e/f/g 轮均覆盖矛/锤、甲飞开启/关闭；长矛双方均产生真实 spear 伤害，有胜有负，样本不足。g 轮新端普通矛负、甲飞矛胜，两场新端均无对局内 Grim 报警；重锤普通局 1200 tick 双方存活、甲飞局负，伤害输出仍明显不足。此前仍出现 Simulation、Post 等报警，不能宣称整体零报警、高胜率或服务器最高速度。h 轮复测脱离滑翔距离修正，普通与甲飞两局均到 1200 tick 双方存活，新端对参考端的有效伤害仍为零；新端各出现一次 Simulation。重锤尚未达到高胜率目标，不能仅因存活时间增加就判定进攻改善。

之前的直向拉升 123.9、斜向拉升 190.7、纯垂直 31.8、斜向巡航 47.6 格/秒来自指定的 Via→1.20.4 测试环境，不能据此保证原生协议或其他 Grim 配置达到相同速度。

证据位于相邻 `work/combat-grim-lab`：`duel-results.json`、每局服务器轨迹、客户端状态、配置快照、source-g/h.json 和完整日志。源码回归、真实对打和发行包启动是三种不同验证；启动成功不证明空战性能。专用候选未签发凭据，不作为可分发会员包。
