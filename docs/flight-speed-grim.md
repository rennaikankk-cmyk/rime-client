# Grim 鞘翅飞行与 GZBoost 验证

后续激进拉升改进已合入，见 [GZBoost 拉升验证](gzboost-climb.md)。本文保留此前巡航 / 下降基线记录。

## 操作

Mode 仍只有 Grim / NoAC。Grim 下方提供 **GZBoost** 开关，默认关闭，关闭时使用普通耦合巡航；冲刺键不参与高速策略选择。开启后，方向键启用高速巡航，潜行键进入高速下降，空格继续拉升。设置随配置保存，NoAC 下隐藏。

不支持双视角的协议连接会回退原有可用控制并提示。纯垂直和空战追击不使用新增高速分支。AdaptiveSlowdown 仍默认关闭。

## 算法和实测

修正了冗余视角恢复包，以及烟花消失时丢失已观测移动惯性的问题。GZBoost 使用独立的动力和包围盒视角；世界坐标轴方向下降时交替偏转，提升前进速度。烟花提前接续只用于高速手动巡航。

`clean07` 四场各 1050 tick，最后 15 秒服务端净位移 / 实际时间：

| 动作 | 水平速度（格/秒） | 垂直速度（格/秒） |
|---|---:|---:|
| 普通斜向巡航 | 47.53 | -0.04 |
| 高速下降 | 280.26 | -30.68 |
| 高速平均高度巡航 | 160.01 | -0.04 |
| 普通斜向拉升 | 45.96 | 193.06 |

高速巡航高度约有 3.31 格起伏，下降额外侧摆约 0.69 格。280 是下降状态的水平净速度，不是定高巡航速度。默认短烟花在普通斜向巡航消耗 64 个 / 52.5 秒，高速下降消耗 117 个 / 52.5 秒。

以上四场主动飞行区间均无传送确认包、Grim 告警、原版移动过快警告。场景重置和登录区间单独保留，不冒充飞行回拉。`clean07` 使用之前的冲刺绑定，最终改为 GZBoost 开关后由 `gzboost08` 补测设置和飞行。


### 最终开关补测 gzboost08

每场 850 tick，最后 15 秒服务端净速度：只按冲刺且 GZBoost 关闭为 47.58 格/秒；GZBoost 开启巡航为 159.29；关闭后普通巡航为 47.71。以上三场主动区间均无修正包和移动告警。默认值关闭、NoAC 隐藏、Grim 显示、配置序列化恢复全部通过。

**高速下降本轮出现一次原版 moved-too-quickly 修正（第 579 tick）。** 最后 15 秒包含恢复过程，水平净速度为 196.32 格/秒，垂直 -29.56。该次警告对应服务端接收到约 27.97 格水平移动，具体造成积压的时序尚未确认。没有观察到该场 Grim Simulation 告警。此前 clean07 的 280.26 结果可复现资料保留，但最终补测说明它不是稳定无回拉的保证；不能仅报告成功场次。

## 环境与边界

客户端 1.21.11，ViaFabricPlus 4.4.2，目标协议 1.20.3–1.20.4；本地 Paper 1.20.4 build 499，原版 Grim 2.3.73，ViaVersion 5.12.0。生存、allow-flight=false、grim.exempt=false，客户端 60 FPS，视距 4，回环网络。

原版 Grim JAR SHA256：`a095331a8ba47286b27bdb9b51f0d35ae4a227632a2c50b25cedba85439f1810`。

**高速验收将 Paper 每玩家区块加载速率 100 → 400，发送速率 75 → 400。** Grim 检查和原版移动检查保持启用。默认区块吞吐的独立实验曾因未加载区块强制同步，持续水平速度约 110–120；因此不能将本次结果宣称为完整默认配置、客户服务器或所有 Grim 版本下的最高速度。尚未验证公网延迟。
