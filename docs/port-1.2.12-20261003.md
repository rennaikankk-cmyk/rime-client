# Minecraft 1.21.1 · Rime 1.2.12 对齐

按用户明确要求，从本分支 1.2.10 同步主分支 `6604120` 的 1.2.11–1.2.12 更新：自动床放置/引爆、字体/HUD 缓存、水晶/TP 放置引爆与自动挖掘补晶配合。保留 1.21.1 的 `ResourceLocation`、GuiBlitCompat、原生潜行指令包、`dimensionType().bedWorks()` 与碰撞 API。

## 原生虚弱攻击适配

1.21.1 实机中，客户端有 Weakness 效果时 ATTACK_DAMAGE 仍可能为 1，效果修饰器集合为空。不能仅按客户端属性认定空手可打晶。`NativeCrystalWeapon` 按已同步药水效果的修饰器 ID 补全估算，避免重复叠加；切到能造成正伤害的武器后，保持至少两客户端 tick 且 150 ms，再由原动作入口重新检查并攻击。

普通水晶和 TP 共用此流程，遵守 AutoSwap、进食与其他模块的持槽所有权。攻击后还原槽位/背包；关闭模块、授权失效、切换世界、被其他动作接管或超时会清理持槽，不恢复过期目标。只允许自己的武器持槽继续水晶攻击；进食等其他持槽仍暂停。

## 验证

- `crystal-auto-1211-lab/release132-final`：21/21 原版实机自动流程，覆盖普通/TP Rotate 开关、真实掉落物占位后改选晶位、虚弱快捷栏及背包武器、武器还原、副手水晶、无材料/自伤停止、AutoMine Rotate 开关、伤害/距离限制及 2000 ms 放置间隔（首次补晶 2046 ms）。
- `bed-auto-1211-lab/release132`：17/17，覆盖下界、末地、床头悬空、侧面/箱子支撑、床尾引爆、背包/副手，以及主世界/无材料/无目标/自伤/目标伤害限制。
- 测试使用生存模式防护 IV 下界合金驾驶员、客户端玩家选择代理和同位置服务端高生命值僵尸伤害观察体，统计服务端实际爆炸伤害。并非真人胜率、Grim 或 Via 验证。
- 挖掘衔接测试关闭 `doTileDrops`，避免随机碎石落点把唯一晶位堵住；掉落物阻塞另由真实 ItemEntity 场景验证。较早试跑中因碎石占位而暂停属于正确的原版放置限制，不以删掉客户端占位检查来通过测试。
- 开发测试工具独立打包，禁止混入会员发行包。生产构建仍执行授权入口与混淆产物检查；发行另按 Rimeguard v3.4.0 完成两通道签名启动和下载验收。

1.21.11 仍为默认版本；1.21.1 后续仍只在用户明确要求时同步。
