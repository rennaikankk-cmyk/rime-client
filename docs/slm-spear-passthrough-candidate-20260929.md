# SLM 长矛光环对照候选：近身穿越方向保持（2026-09-29）

承接同日《SLM 长矛光环补充交接》。基线 `9c18b2c`。按交接 §5 的最小候选范围实施：
**保留 Rime 全部蓄力、武器控制、甲飞眼高与地形恢复逻辑，只新增"近身穿越后保持动量方向"**，
默认关闭，作为三组对照（当前 Rime / 仅加方向保持 / SLM 基础版）中的实验组。未移植 V2/V3、
未改拉开节奏、未动防矛/最小射程/贴地恢复，也未把 SLM 的死代码（`canAdjustMovement` 恒假、
地面抬升分支不可达等）当成升级。

## 实现

- `util/elytra/SpearPassThroughHeading.java`（纯逻辑，15 项夹具检查）：
  - 目标落到真实水平移动方向**后方**（归一化 dot < -0.2）时，近身请求的水平分量改沿当前
    穿越方向，幅度取当次请求；**垂直分量原样保留**（交接明确警告 SLM 对整三维取反会改变升降）。
  - dot 死区 ±0.2：横向擦过不左右摇摆；水平速度低于 0.02 b/t 或请求近乎垂直时不做选择。
  - 保持以**目标实体 ID + 单次穿越**为界：目标回到运动前方（dot > +0.2）、超过 20 tick 或
    换目标即结束；进入时方向冻结，不随中途漂移改向。
- 接入 `GuangxiElytraChaseModule` 的 `tickNearFollow` 普通接近分支（`SpearPassThrough` 开关，
  Advanced 页，默认关）；离开 NEAR_FOLLOW / 重置状态机时清空保持。其余路径（蓄力腾位、
  防矛、限步接近、拉开）全部不变。

## 与 SLM 原实现（ElytraBot.java 2283–2290）的差异清单

| SLM 原版 | 本候选 |
|---|---|
| `look.negate()` 整三维取反 | 仅水平分量重定向，垂直保留 |
| `dot < 0` 即触发，无死区 | 归一化 dot ±0.2 死区 |
| 无时间界、无目标界，逐 tick 重算 | 单目标单次穿越，20 tick 上限，方向冻结 |
| 幅度来源含至少 6 的请求向量 | 幅度取当次请求水平长度 |

交接第 4 节列出的 SLM 缺陷（绕行不可达、地面抬升死分支、远端就绪判断读错物品、旧协议
时长截断、窗口语义、远追方向重复加高）均**未**照搬。
