# 水晶 / TP 水晶放置引爆与自动挖掘联动

基线：Rime 1.2.11，`8370317782b9d1f43b9f2f9686e8c211fb0d8d08`，Minecraft 1.21.11。

## 修复

1. 普通水晶开启 Rotate 时，恰好位于 3 格攻击边界的水晶能够放出，但旋转射线 `AABB.clip` 不接受恰好终止在表面的线段端点，浮点方向误差进一步放大边界问题。方向归一化并给线段增加 `1e-6` 几何容差；候选距离过滤、遮挡、墙距和最终旋转确认仍保留。实机旧版 Rotate off 成功、Rotate on 放置 1 次攻击 0 次；候选两种状态都产生真实爆炸伤害。

2. TP 水晶预判能否安全引爆时误用单格方块包围盒，实际引爆则使用 2×2×2 的水晶实体包围盒。两条路径现在统一使用 `EntityType.END_CRYSTAL.getDimensions()`。基线测试中的安全位置被错误排除，TP 完全不放晶；候选能自动放置和引爆。没有放宽 MaxSelfDamage 或生命余量。

3. TP 扫描忽略掉落物和临死实体，但共享的最终放置入口及原版 `EndCrystalItem.useOn` 会拒绝这些占位。现代协议扫描改为匹配最终检查，允许继续选择可用次优底座。放置占位柱仍为 1×2×1，与实际水晶的攻击包围盒用途不同。

4. TP 引爆复用普通 DEFAULT 水晶的武器准备逻辑。虚弱下主手伤害不足时，按普通水晶 AutoSwap 范围找武器并还原；NONE 仍拒绝自动切换，进食/武器控制暂停仍有效。独立 TP 不要求普通水晶处于启用状态。共享入口保留授权检查，控制流和混淆回归增加该入口的检查。

5. AutoMine 调用的 `preplaceCrystal` 补晶入口遵循水晶的材料、PlaceDelay、可引爆距离、MinDamage/FacePlace、Balance、自伤和占位规则，成功发送后推进放置间隔并记录真实预测伤害。服务端确认挖空前不会把实心方块当成可用水晶位置。

6. PacketMine 的同步 Silent 工具切换/还原使用局部标记，使水晶不会把这类工具事务当成手动换槽而不断刷新 SwitchPause。Visible / Manual 切换保持原有暂停行为；标记通过 finally 恢复。

7. 每轮普通水晶选点开始清除上一轮的 `placeSearchWaiting`，避免目标或候选消失后的提前返回保留旧等待状态。

## 实机验证方法

新增 `tools/crystal-auto-probe`：启用真实模块，通过正常 tick 自动寻敌、选点、换槽、发包，不注入候选或调用私有动作。生存玩家使用保护 IV 下界合金甲，无抗性效果；客户端玩家代理供玩家专用筛选器使用，同位置服务端僵尸记录实际爆炸伤害。含正常链路、掉落物次优点、虚弱、副手、缺材料、自伤拒绝，以及 AutoMine + PacketMine 挖开后放晶和引爆。

同一套 19 场景的基线保存在 `../crystal-auto-lab/baseline4/results.json`，通过 12/19。失败项为普通 Rotate on、五项 TP 正向场景、自动挖掘 + Rotate on。候选在 `../crystal-auto-lab/verified/` 通过 **19/19**，同时保留负向场景的正确拒绝行为。设置 PlaceDelay=2000ms 的联动场景首次放置在 2003ms；MinDamage 和 BreakRange 拒绝场景挖开成功但放置/攻击均为零。源码与结果 SHA-256 保存在 `../crystal-auto-lab/verification.json`。

共享爆炸回归 `../blast-lab/crystal-mine-fix-20261003/`：**76 项检查、18 个服务端真实爆炸伤害对照、5 条模块动作链全部通过**，包括 TP 水晶完成后的服务端位置/朝向还原；预测伤害最大误差约 0.000031。开发测试日志出现 Mojang/Realms 离线身份及外部网络请求警告，未影响本地集成服断言。

生产参数 `gradlew --offline build` 成功：131 个任务；授权动作/清理控制流 **797 项**，混淆产物 **45088 项**。日志：`../crystal-auto-lab/production-build.log`。这次没有部署生产或替换会员下载包。

最初未附魔护甲的试跑因超过 MaxSelfDamage 被正确拒绝，不算模块故障，也不作为前后修复比较；旧的掉落物试验曾把备选底座放在普通攻击距离之外，已调整后使用相同最终夹具重跑基线和候选。

这些数据证明原版集成服中的动作链与边界修复，不代表真实玩家胜率、长距离 TP、Via 或 Grim 验收。没有同步 1.21.1，也没有变更生产发布版本。
