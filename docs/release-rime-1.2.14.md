# Rime 1.2.14 · Rimeguard v3.4.0

改进重锤／MXS 和矛的空战追击、回转与出手时机，减少追击时多余爬升和撤离过冲。平地移动目标使用有上限的拦截预判，遇到障碍收短预测，保留真实距离、视线和攻击冷却检查。

低顶盖下不再反复要求不存在的落锤空间；开启重锤额外普攻时可按冷却攻击，落地后允许普通步行接近。目标被击退到门外时保留短暂地面策略，减少屋檐边反复切换。

新增默认开启的 `CaveEscape`，与 `TerrainGuard` 配合：持续受阻后沿仍可通行的来路回退，改进窄道转角和下降通道；落地后检查站立空间及脚下支撑。手动移动可以接管。没有有效来路、入口被封或地面路线有高差时不能保证自动脱困。

完整回归已通过。服务端平地和低顶盖无还击靶子测试完成击杀，但不代表 PvP 胜率；仍观察到个别移动纠正，复杂天然矿洞尚未实机验证。详见 [空战循环诊断](aerial-attack-cycle-20261004.md) 与 [平地、遮挡和矿洞验证](ground-and-cave-20261004.md)。
