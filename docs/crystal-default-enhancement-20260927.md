# DEFAULT 水晶增强与实测记录（2026-09-27）

本轮完成源码修改和开发环境实测，基于已发布的 `3a56ef8`。尚未替换 GitHub 发布标签、官网和登录器发行包。

## 已完成

- DEFAULT 保持当前候选伤害上界降序，避免过期异步提示占据首位，干扰旧点锁的释放和搜索剪枝。Rusher 继续原有路径。
- DEFAULT 目标伤害按当前方块遮挡计算；预计挖开、炸开后的无遮挡场景只参与额外自伤风险评估。低爆抗方块不再直接当成已经消失。
- 修正完全遮挡和爆炸半径边缘仍有基础伤害的边界，符合 1.21.11 原版计算；Rusher 原行为保留。
- 使用实体实际碰撞体积，并以不超过 0.5 格的路径段检查碰撞和沿途自伤，避免高速越过薄墙及只看当前位置/终点的问题。路径最多 129 个位置，计算量有界。
- 新增默认开启的 `AdaptivePredict`：预测时长参考延迟和服务器 tick 时长，以配置为上限；高速自身移动即使 `SelfPredict=0` 也自动预测。关闭自适应并将 `SelfPredict=0` 可禁用自身预测；关闭 `Predict` 可停用预测。
- GZBoost 预测使用实际应用速度，并在巡航控制器的副本上预览下一拍方向，覆盖平飞上下交替、俯冲左右交替。预览不修改飞行控制器状态、不发转头包、不改变飞行参数。
- 更新对应中文设置说明。无旋转模式没有增加反作弊限制；现有授权、心跳、水印、保护链保持不变。

## 原版 1.21.11 真实爆炸

在本机实际运行 Minecraft 1.21.11 客户端和原版集成服，复制独立测试世界。引爆服务器中的真实水晶，读取目标实际生命扣减。共六组，最大绝对误差约 **0.000027 生命值**。

| 场景 | 保留的旧遮挡算法 | 新预测 | 服务器扣血 |
|---|---:|---:|---:|
| 无遮挡 | 47.666668 | 47.666668 | 47.666687 |
| 石墙 | 47.666668 | 1.000000 | 1.000000 |
| 黑曜石墙 | 0.000000 | 1.000000 | 1.000000 |
| 半砖遮挡 | 47.666668 | 7.346667 | 7.346680 |
| 护甲 | 44.616001 | 44.616001 | 44.616028 |
| 清除遮挡后 | 47.666668 | 47.666668 | 47.666687 |

“旧遮挡算法”是在同一场地调用保留的 Rusher 几何计算所得，只用作公式对照，不能称为两套完整客户端的 PvP 胜率对比。

同一实机夹具还验证了真实选点、放置和攻击链路：**1 次成功提交放置、1 次成功提交攻击，服务器扣血 50.93341**。目标缓存由服务器拥有的僵尸提供，避开第二个玩家账号的需求；生产的玩家专用过滤未变。这验证动作和服务器扣血，不代表完整自动玩家寻敌或真人对战。

最后一次运行 `candidate-final3` 共 **42 项检查通过**。其中过期提示取自当前候选列表的最低伤害位置，并将待确认窗口设为 1000ms 消除夹具计时波动：保留的旧顺序得到空结果，DEFAULT 成功解锁并找到可放位置。早先两次固定坐标反例未触发旧行为，属于无效复现，未计作通过证据。

## GZBoost 实际飞行

实际 1.21.11 客户端经 ViaFabricPlus 连接既有 1.20.4 飞行测试服；固定航向、空旷场地、低延迟。每种场景运行 500 tick，统计第 300–500 tick 的 201 个样本。以下是实际相邻位置计算出的水平速度，而非单独读取速度字段。

| 场景 | 速度中位数 / P95（格/秒） | 下一 tick 水平误差中位数 / P95（格） |
|---|---:|---:|
| 平飞 | 157.507 / 159.775 | 低于日志 0.000001 精度 |
| 俯冲 | 276.556 / 279.038 | 0.000145 / 0.000146 |

这两段采样的垂直误差也低于日志精度，实际飞行期间无界面干扰、无传送确认。登录准备阶段的网络/反作弊日志未混入飞行结果。速度保持在此前约 159 平飞、278 俯冲的范围，不宣称打破最高纪录。

上述精度仅验证下一 tick、固定输入、低延迟条件。高延迟、多 tick 预测、突发转向、外部击退、烟花续接与真人空战仍存在预测不确定性；远程目标采用短时运动估计，不能获知对手未来输入。
