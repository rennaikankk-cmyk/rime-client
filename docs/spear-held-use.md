# 长矛持用与甲飞（2026-09-19）

本次修复两个可复现的功能冲突，尚未证明长矛实战强于旧版。

## 行为

胸甲控制器仅交换胸甲槽与非选中的装备热键栏槽。此前无条件拒绝所有使用物品，持矛蓄力便阻塞甲飞换甲。现在允许仍在实际使用手中的同一 KINETIC_WEAPON 栈继续使用；食物/盾、手动换槽、打开容器、鼠标持物、锁存、装备对变化等保护保留。实际烟花使用仍须先让出持用。

拉开距离和防御动作切换此前主动释放长矛，造成反复重新蓄力。现在已经由追击控制器拥有的持矛可以持续；开始持矛仍受目标距离控制。窗口到期、补烟花、手动接管、目标/会话失效和避障清理保持有效。防御只维护已有持矛并清除攻击朝向，不发起额外攻击。MXS 的防御转换保留其长矛阶段，不重新进入整个 MXS 的重锤阶段。

## 验证边界

`ArmorSwapHeldUseTest` 和新增 CombatHook 检查分别先在旧行为跑出预期失败，再修复。定向通过：HeldUse61、ArmorSwapCycle1153、CombatHook430、Lifecycle239、Weapon32、CombatPolicy87、SpearCombat。测试包括真实编译接线、持物身份矩阵、非长矛路径继续释放、MXS阶段/朝向清理、烟花让位；它们不能代替实服性能试验。

同机隔离运行原始 `SlimefunHelper-1.21.1-1.1.5.4-yclimb-default8.jar.disabled`（SHA256 `1b70f13627d0c638a016b089e9d52c4a3b33c32ec1f920b9988ed95aa39c445c`）加 `729.nbt`（`d9eb60ef708057aea51c9ee1c11b55545777b51a69cb803f0d31f1bafd01088a`）。旧版1.21.1经ViaProxy连接1.21.11原版机制实验服；未安装反作弊。v10.4.26没有替代此主对手。

729默认重锤且自动使用关闭；SPEAR试验显式切旧模式、选长矛槽、开启其原生AutoUse，其他载入参数保留。旧客户端没有VFP时，持矛冲撞仍在服务端造成真实长矛伤害；VFP门控属于点刺路径，不能泛化成整个长矛模式不可用。
