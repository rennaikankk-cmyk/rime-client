# SlimefunHelper 功能适配与飞行协作

本轮适配参考 SlimefunHelper 官方 1.21.11 分支 `326ada8b16d579534e35cba0b60b8f47d0ca3213` 的动作确认、防水晶占位和环境投掷思路，使用 Rime 自己的模块、授权、换槽及旋转管理。没有整段覆盖上游飞行或战斗核心。

## 使用设置

| 模块 | 设置与行为 |
|---|---|
| 甲飞 | `CruisePriority=true` 默认保住 GZBoost 手动巡航的鞘翅状态；空战接管后允许换胸甲，下砸时继续让行。巡航 HUD 显示“甲飞待命”时没有提供胸甲防护。 |
| 甲飞实验延迟 | `GlideTrackerDelay=0` 默认关闭。大于零只作用于独立甲飞，不作用于已开启的飞行控制器。只缓冲停止滑翔的标记，其他元数据即时应用；发生相关回拉后禁用延迟，换世界/重生重置。不要将其当作无回拉保证。 |
| 空战 | `OnlyWhenNoWasd=true` 适合手动巡航与追击交替：按方向键时交还手动飞行，松开且有目标时追击。手动开启的飞行模块在空战退出后保留。 |
| 防水晶占位 | 默认关闭。支持已装填多重射击箭弩、无爆炸烟花和展示框。检查可见黑曜石/基岩、实体占位和交互距离；默认附近有敌人才消耗物品，默认让行自动水晶。弩用完需要重新装填，烟花占位时间短。 |
| 智能投药 | 默认关闭。默认贴地、低于 16 生命值且附近无敌人才投治疗/再生药水；可选顶板、垂直上升、滑翔和有益效果维护。禁止含负面效果的药水。 |
| 修甲瓶/一键投药 | 先等待普通移动包携带稳定瞄准，再使用物品。修甲瓶批次最多六个，等待服务端确认；一键投药自动结束，持续被占用时超时退出。 |

新工具动作让行 GZBoost、空战、重锤下砸、甲飞换装、打开的界面及正在使用的物品。Rusher 激活时始终让行，不修改 Rusher 水晶核心、连接分发或旋转管理器。

动作记录只在最终获准发送后捕获当前手中物品副本。累计 ACK、超时、回拉、断线和换世界清理记录；ACK 表示服务端处理序号，并不证明命中或成功放置。

AntiReplenish 仍属于后续候选，本轮没有加入自动拿取、丢弃或挖潜影盒。新 HUD/设置说明集中在功能状态与暂停原因，没有重做现有 GUI 主题。

## 验证与发行

`GlideMetadataDelayTest` 覆盖无关位保留、覆盖顺序和延迟期限；`PendingSequencesTest` 覆盖累计 ACK、容量、过期及会话重置。真实客户端在本地 Paper/Grim 测试服验证物品实体、治疗效果、飞行与控制切换；开发测试必须使用 `-PgzwDevelopmentBuild=true`。

当前基线的四个旧旋转钩子测试与 Rusher 旋转实现不一致。本轮保留其失败，不通过修改 Rusher 或削弱断言来消除失败。完整 `check` 未通过之前，不把此分支标为正式发行验收通过，也不生成交付用混淆包。
