# 空战与 GZBoost 协作更新

基线 `35b2214`（Rime 1.2.3），本轮为 Rime 1.2.4。沿用攻击距离、真实下落、目标规则、服务器伤害确认与装备恢复。

## 行为

- GZBoost 的追击预判、长矛蓄力距离和威胁判断共用最近实际应用的运动向量。只接受同一玩家/世界、连续滑翔中的零至一 tick 样本；回拉、冲量、碰撞、恢复暂停、异常运动和过期样本退回当前游戏速度。下一重锤回合不会再把过期应用速度当成规划预算。
- 长矛按双方相对运动提前进入准备阶段，迎面高速交会提前蓄力。近战时保留请求长度，避免 GZBoost 将已经足够的短请求再次扩张；撤离和侧闪保留各自方向。所有这些范围是导航准备范围，最终伤害仍由原版长矛组件与服务器查询决定。
- 长矛远距离追击允许 GZBoost 参与；接近攻击区间、地面航道、让出蓄力空间和脱离阶段保持方向，不引入巡航高度往返。实际双视角仍受原有 Via 协议能力门限制。
- 空中自动蓄力原先可以跨越烟花失效一直占用手，直到长矛伤害窗口结束。现在补烟花到期时，最多保留两 tick 临近攻击机会，再释放自己持有的蓄力，交给既有烟花/甲飞窗口补充；不会改变手动使用物品的所有权。
- 重锤 GZBoost 拉升接近可达的最高点时，保留目标漂移并逐步消除位置误差，取消近距离的轴向加速。远距离拉升仍使用原有加速；自然下落不补烟花，不扩大攻击距离。
