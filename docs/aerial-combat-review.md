# 空战执行与状态优化（2026-09-21）

本轮延续 Aura 升级，审查 AerialCombat 的目标判断、重锤出手、长矛使用、转头与飞行控制协作。普通飞行、鞘翅滑翔和穿甲滞空仍按观测到的装备及位移处理，不假设对方一定在使用甲飞。

## 已改动

- 重锤范围、瞄准和遮挡统一使用接收到的目标碰撞箱，避免渲染插值位置与实际瞄准位置不一致。最近点被遮挡时尝试其他候选点，最终仍检查实际提交角度的射线。
- 攻击、转头、切槽均以最终本地提交的包为准，正确处理取消和替换。被取消的攻击不重置冷却、不启动新命中等待；普通右键交互也不会清掉先前的攻击反馈。
- Mace 页增加 `Rotate`、`YawStep`、`MoveFix`。关闭 Rotate 时仍要求当前已提交角度能命中。分步转头服从飞行安全优先级；换目标、模式、战斗阶段、武器或遭遇回拉时清理旧请求。
- 共享切槽管理器跟踪最终提交槽位，并在玩家、世界和连接切换时重置。空战武器控制会等待切槽提交，失败后下一 tick 重试。
- 长矛开始使用包被取消时撤销本地虚假蓄力；仅管理自己发起的使用动作，保留玩家手动操作的所有权。
- 已加载区块内结合脚下碰撞体判断落地，防止空中 `onGround` 标记把追击错误切成地面模式。观测到滑翔时不判为落地；未知区块保留标记回退。
- 空目标扫描改为每四 tick 一次，目标失效时立即重新搜索；固定目标仍保持锁定。
- 自身回拉清理旧路径、长矛承诺、转头、武器控制、闪避方向和待确认命中；授权失效时同样允许完成必要清理。

## 验证

新增几何、搜索节奏、落地判断及授权动作检查，并更新已有空战字节码回归。真实 Minecraft 1.21.11 开发客户端测试：AerialCombat 37 项、Aura 28 项，共 65 项。覆盖取消／替换包、接收与显示位置分离、部分遮挡、普通空中目标、假落地、仅上半身碰撞、切槽重试、长矛蓄力、回拉和分步转头生命周期。

测试入口：`tools/aura-fixture/run.ps1`。测试模组只存在于开发测试运行，不进入发布 JAR；脚本完成后恢复非开发构建标记。官网版和专用版均要求完整 `build`，包含回归及混淆产物保护检查。

本地提交确认不等于服务器接受命中。本轮没有宣称实服命中率或 FPS 提升，也未进行发布候选 JAR 的双 JDK 启动验收；未推送或发布。后续最有价值的调优是根据实际服务器的命中、回拉和延迟记录校准重锤拦截高度与 MXS 切换时机。
