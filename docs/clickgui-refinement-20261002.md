# ClickGUI 布局与视觉整理

玻璃面板使用统一的 126 宽度、24 标题行、19 模块行和 8 间距。按逻辑视口自动换行，保留顶部工具栏和底部提示空间。暖灰底色、陶土色细侧线、较轻的悬停底色与细轨道滑条区分状态；按键简写和按实际字重测量的省略文本避免挤占模块名称。

搜索框与六个工具按钮保留独立空间，搜索结果临时集中排列，不改写用户保存的面板位置。搜索复用文本控件的选区、光标、横向滚动与点击定位。设置名称和数值使用分开的宽度预算；布尔设置为名称保留更多空间。

分类列只计算显示坐标，不再覆盖玻璃面板的坐标或折叠状态。视口缩小时只限制显示位置，恢复窗口后仍使用原保存坐标。拖动结束按四像素网格对齐；工具栏的整理按钮清除手动位置及折叠覆盖，恢复自动排布。旧三字段 PanelLayout 配置继续读取；第四字段仅区分自动排布与手动位置。空白区域滚轮不再移动整组面板。

实机截图发现共享 GUI 网格的部分圆角填充和直线边框具有反向顶点顺序，导致 GUI 管线背面剔除。网格提交前现统一朝向，并保留每个顶点原有颜色。回归覆盖方框、1.5/3/8 半径圆角和边框的两个三角形。

验证：`clickGuiLayoutTest` 2,478 项（六种逻辑视口、三种菜单比例及非法比例回退）；`guiMeshWindingTest` 276 项。独立测试模组 `tools/clickgui-probe/` 的最终 `review03` 在真实客户端完成 118 项检查与七张截图，覆盖中英文、搜索展开、分类列、布局恢复、缩放、折叠、拖动、整理与搜索快捷键。Minecraft 会限制 GUI scale 最大值，最后两张请求不同缩放但实际视口相同；不夸大为七种窗口大小。

截图与哈希记录在本次工作区 `outputs/clickgui-refinement/`。探针使用隔离实例、现有开发授权门和本机字体，不包含客户凭据，也不打入发行客户端。这是视觉/交互验证，不是 FPS 基准或生产签名发行验收。
