# rc22 combat.1 / direct.6 发布说明

发布日期：2026-09-21。官网版 `1.3.1-rc.22-combat.1`，同功能专用版 `1.3.1-rc.22-direct.6`。

本次累计范围为上次官网发布 `1.3.1-rc.22-placement.2`（578cf84）之后的全部功能提交：3170a17、0c68495、237e681、b5c2ba1、61ba0d9。保留之前的放置、锚策略和原位红石复用改动。

- 放置视觉：水晶、锚、床、活塞水晶及 TP 放置统一动画与淡出；水晶底座和床的外形对齐，增加执行阶段、伤害等信息及遮挡显示选项。按经过时间计算平滑，降低 FPS 对动画速度的影响。
- 挖掘视觉：PacketMine、AutoMine 等接入统一方块视觉。世界信息改为方块内的精简缩写，合并和安排同位置标签，减少重叠。
- 转头：需要转头的模块独立配置 Rotate / YawStep / MoveFix，按最终提交角度确认，处理包取消、替换和模块优先级；关闭或失效后清理旧请求。
- Aura：替代 AutoSword，保留旧名称与配置入口；增加 Single / Switch / Multi、目标排序及过滤、武器选择、盾牌策略、自然暴击、冷却与 TPS 处理。多目标按冷却轮换，每次最多攻击一个。
- Aura 可选 TP：默认关闭，使用有预算和碰撞检查的分段往返路线；发送失败时停止攻击并尝试返回，位置纠正后默认停止 TP。服务器仍可能拒绝移动或命中。
- Offhand：替代 AutoTotem 名称，保留自动图腾；避免旧爆图腾异步回调清掉新副手物品。
- 空战：按实际观测处理普通飞行、滑翔及穿甲滞空；脚底支撑检查防止假落地。重锤统一接收位置、距离、遮挡和实际转头；飞行安全优先。切槽失败重试，取消的攻击不消耗冷却，取消的长矛使用不保留虚假蓄力。回拉、换武器与阶段变化清理旧状态，减少无目标扫描。
- 配置：旧 AutoSword / AutoTotem 的存档 ID、旧名称和按键兼容；旧 Aura Delay / Criticals 按新的冷却及自然暴击选项迁移。生产构建保留授权、心跳、水印与混淆保护；专用版保留签名完整性及远程停用策略。

开发客户端 Aura 28 项、空战 37 项集成检查通过；两版完整回归及混淆检查通过。发布必须对最终 SHA256 完成 Microsoft 21.0.7 和 Adoptium 21.0.12.1 初始化、图集及 20 秒稳定启动检查。运行记录与部署校验保存在本次发布证据目录。启动和本地集成测试不等于实服命中率或反作弊兼容性验证。
