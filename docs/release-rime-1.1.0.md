# Rime 1.1.0 — 巡航协同、水晶修复与 dickguard3.0

- 恢复已测的 GZBoost 耦合巡航配置，改善巡航与空战接管、甲飞换装间的衔接。
- 合入经筛选的 SlimefunHelper 功能：AntiCrystal、AutoThrow、物品使用确认，以及补瓶、药水和甲飞的协同修正。新增功能默认关闭，可按需启用。
- DEFAULT 水晶在 Rotate=false 时不再要求准星对准；虚弱时按 AutoSwap 使用有效武器，攻击或取消后还槽；无效攻击不消耗重试。
- 修正垫黑曜石的多人伤害击杀误判；HUD 明示附近爆炸次数，避免与自身水晶 CPS 混淆。Rusher 的攻击与旋转行为保留。
- 接入 dickguard3.0：启动前完整性和签名授权、会话绑定入口、运行期授权联动、三态完整性及环境观察；保留原有会员、HWID、水印与逐动作授权保护。

客户端版本为 1.1.0，防护版本独立为 dickguard3.0。已于 2026-09-27 发布到官网和登录器 1.21.11 下载源，完整记录见 docs/releases/rime-1.1.0/。没有测得新的水晶爆速或对战胜率，不作提升承诺。
