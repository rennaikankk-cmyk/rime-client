# GZBoost 拉升改进（2026-09-22）

## 实现与使用

沿用老版 V2 / YCorner 按各轴可用范围推进的思路，GZBoost 开启且双视角可用时增加拉升策略。世界坐标轴附近交替偏转范围朝向，使用真实侧向位移增加水平动量及升力；世界 45° 对角附近交替利用两轴范围。两个增强区分别在距世界轴 0–5°、距对角 0–3° 内平滑过渡，中间航向保持原有角度算法。

GZBoost 关闭、双视角不支持和空战的普通三参数 Intent 保留原控制。严格原位上升仍不产生水平位移，没有把水平往复或盘旋称为原位直升。GZBoost 烟花预补扩展到拉升；无 GZBoost 的动力复用不变。没有增加新的用户选项。

内部参数：沿轴运动俯仰目标 -89.25°，范围偏航相对航向交替 ±72.5°；对角运动俯仰目标 -89.25°，范围偏航交替 ±45°；范围俯仰均为 0°。原有范围 1.7、余量 0.002 和总速度上限 15 格/tick 保留。各轴对接近零的 sin/cos 分量使用同样容差，避免东西与南北方向不对称。

- climb11 已完整完成东西方向（上升 215.41）、1° 航向（202.22）、43° 航向（197.46）和中途按左键转向再恢复四场。第五场原位上升在第 440 tick 因会话中断停止，不计完整验收；climb12 单独完整复测原位上升 31.76，水平速度 0。
- 上述已完成的最终五场，主动区间无传送确认、Grim 告警或原版移动过快警告。
