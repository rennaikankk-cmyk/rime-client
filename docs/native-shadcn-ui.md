# 原生 shadcn 风格界面

界面沿用 TargetHUD 的 Geist 字体、中文回退字体与圆角结构，菜单及小卡片参考 [InternalBeyond](https://github.com/Sui-IB/InternalBeyond) 的雾蓝、月光文字、半透明面板与细边框。TargetHUD 默认结构、配色不变。直接使用 Minecraft GUI 渲染，不引入 React、WebView 或浏览器运行时，也不复制参考站点的背景图片。

## 使用

- 原 ClickGUI 快捷键保持不变。左侧分类，中间模块，右侧设置；模块右侧开关负责启停，点击名称打开设置。
- Ctrl+F 搜索模块名称、显示名称和说明；滚轮分别滚动模块、设置和顶部设置页。Tab / Shift+Tab 移动焦点，Enter / Space 操作。
- 数值既可拖动滑条，也可点击数值精确输入。文本支持中文、Unicode、选区、Ctrl+A/C/X/V。Enter 应用，Esc 取消。
- 枚举点击后展开选择，较长列表可滚动。颜色支持 #RRGGBB / #RRGGBBAA。右键设置恢复默认。
- 快捷键录入支持键盘和鼠标；Delete 清除，Esc 取消。
- 左下方“编辑 HUD”进入布局编辑器。拖动元素，开关单项、重置布局；位置保存到原 Hud 模块配置。没有实时数据的元素明确显示“预览”。
- 主菜单沿用原版按钮行为，包括多人游戏可用性限制、单人、Realms、语言、设置、无障碍和退出入口。
- 编辑 HUD：鼠标放在元素上滚轮缩放（每档 5%），右键元素或右侧列表名称直达该元素外观页；左键列表名称选择，右侧开关启停。Hud 模块中每个元素都有独立设置页。
- 全部 10 个 HUD 元素支持 50–200% 大小、背景颜色、文字颜色、强调色和 0–100% 背景不透明度。0% 隐藏面板，物品图标和文字保持清晰；颜色输入末两位可另调对应颜色的 alpha。敌友、警告等语义色继续服从原专用颜色设置。
- Client → ClickGui → 菜单大小 (%) 同时调整 ClickGUI 和主菜单（60–150%）。窗口不够大时自动适配，不覆盖保存的大小。HUD 同样按视口适配，缩放后的拖拽边界与实际画面一致。
- 大小、颜色、透明度均保存到原配置；右键相应设置恢复默认。HUD“重置布局”只重置位置。

## 甲飞入口迁移

甲飞换装只由 Movement → 甲飞（ArmorFly）控制。GuangxiElytra / Tricks 不再提供第二个 ArmorFly 开关，飞行方向控制与甲飞换装仍可独立开启。

完整旧配置迁移保留原有效状态：独立甲飞已开，或飞行已开且旧甲飞选项已开，则保留甲飞开启。原先关闭飞行的配置不会因为残留选项自动启用换甲。仅指定旧甲飞 true、未指定飞行 Enabled 的部分配置视为明确开启甲飞。保存后不再输出旧选项。

随项目提供的预设保持相关模块关闭。需要换甲时先开启独立甲飞，再按预设说明启用追人或飞行。

## 验证范围

配置迁移检查覆盖两套旧开关与飞行启停组合；真实文本控件检查 Unicode 删除、选区替换、空输入边界。完整构建包含飞行/战斗回归和混淆检查，新 HUD 编辑器的 Screen 覆写亦纳入产物校验。实际游戏截图、启动和交互记录存放于本次本地验收目录；未完成的运行验证不以编译成功替代。
