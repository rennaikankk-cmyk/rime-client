# 鞘翅飞行：Grim / NoAC

界面保留两个模式。`GuangxiElytra` 是兼容旧配置的内部 ID，显示名称仍为 ElytraFlight。

| 设置 | 用途 |
|---|---|
| Mode | Grim：自动烟花巡航和拉升；NoAC：直接控制速度 |
| SpeedBps | NoAC 水平速度，格/秒，默认 40 |
| ClimbBps | NoAC 升降速度，格/秒，默认 40；与水平速度独立 |
| AutoFly | 没有按方向键时继续向前；空格/潜行仍控制升降 |
| FreeLook | 镜头自由转动，保持飞行航向 |
| TerrainGuard | 路线避障；基础碰撞检查和落地恢复仍保留 |
| AutoEquip | 起飞自动寻找并穿上鞘翅 |
| AdaptiveSlowdown | 仅 Grim：回弹后累计降速并缓慢恢复；默认关闭 |

Grim 隐藏两项直接速度设置。模式之外没有角度、包络、双视角、补烟花周期等调参页；它们由内部策略处理。模块通用的开关、按键、显示名称仍保留。

WASD 控制水平，空格拉升，潜行下降。仅按空格是尽量保持水平位置的垂直上升；前进加空格能利用滑翔升力，更适合快速爬高。AutoFly 开启时，只按空格也会继续向前拉升。NoAC 松开按键、关闭 AutoFly 后悬停。

## Grim 实现

- 预测起点使用连续两 tick 的真实位移，修复客户端烟花在移动后再次修改速度导致的重复衰减。碰撞、外力、爆炸、异常状态、传送、断线和模式切换会使采样失效或重新建立。
- 双视角只在支持的 ViaFabricPlus 目标协议上启用；实测目标为 1.20.3–1.20.4。未安装 Via 或目标为 1.21+ 时自动使用单视角，并在每次连接的聊天栏提示一次。
- 当前移动视角、烟花附着状态、控制权和最终碰撞检查全部通过后才应用巡航结果。追加旋转保持连续角度，并在最终碰撞否决之后决定是否发送。
- 提前补充烟花并考虑往返时延。旧协议没有显式烟花组件时按较短寿命估算：Via 可能把旧 NBT 默认 Flight=0 显示为现代 Flight=1。此兼容策略会增加这类烟花的消耗，以减少高速拉升供能空档。
- 追击、重锤自然下落、独立甲飞换装与地形恢复继续保有控制权，手动巡航不抢占这些动作。
- 旧 Freeze / GrimBoost / GroundHop 等选项退出配置注册，导入旧文件也无法重新启用。旧遥测接收字段保留，只报告内部实际策略。

## 配置迁移

旧 VOID 模式迁移为 NoAC，旧速度从格/tick 乘 20 转成格/秒。旧无限制 FIREWORKS（关闭缩放且没有启用耦合巡航或 GrimBoost）也迁移为 NoAC。其余旧烟花模式迁移为 Grim。新 Mode 明确指定时优先，部分配置不重置没有指定的模式。绑定、模块开关和常用选项保留；重新保存后移除旧调参字段。

## 本地实测

2026-09-22，1.21.11 开发客户端 + ViaFabricPlus 4.4.2，目标 1.20.4；Paper 1.20.4 build 499 + Grim 2.3.73 + ViaVersion 5.12.0。生存模式、allowFlight=false、没有 Grim 豁免，回环网络。Grim 检查阈值保持默认，启用控制台完整告警；服务器禁用网络压缩以避免这组协议桥接组件在登录时的压缩包错误。

每场 420 tick，跳过预热，按服务器接受的位置和实际经过秒数计算均速，排除场景重置传送。两端同时记录，客户端显示的峰值不作为测速结果。最终复测记录如下，完整摘要另存 `flight-grim-acceptance.json`。

| 动作 | 水平均速，格/秒 | 垂直均速，格/秒 |
|---|---:|---:|
| 直向巡航 | 33.68 | 0.00 |
| 45°斜向巡航 | 47.61 | 0.00 |
| 直向拉升 | 32.47 | 123.88 |
| 45°斜向拉升 | 45.93 | 190.67 |
| 原位垂直上升 | 0.00 | 31.79 |
| AutoFly + 空格 | 32.49 | 123.96 |

对照组是本轮收敛界面后、仍使用旧运动计算的版本。旧直向/斜向拉升约 14.27 / 12.23 格/秒，且出现 Simulation 告警。下降场景会接近地面并触发避障，因此不当作自由空域下降速度上限。

七场主动飞行阶段没有控制台 Grim 告警；高速下降一场有一次服务端位置修正，回拉冷却恢复正常，因此不能称为全场零回拉。登录预热阶段还有 Timer/Simulation 告警、重置传送时有 moved-too-quickly 警告，完整原始日志保留，未把它们算作稳定巡航数据。

以上是指定版本、低延迟条件下的有限测试，不是所有服务器、所有 Grim 配置或所有飞行算法的绝对最高速度证明。1.21.1 与专用分支同步实现并分别构建；表中速度来自 1.21.11 主分支，不冒充另外两个分支的独立飞行实测。

NoAC 在独立、未安装反作弊的 1.20.4 测试服检查了水平 60、拉升 80 格/秒、两者同时输入、AutoFly 拉升和松键悬停。模块真实注册项及旧配置迁移也由游戏内测试程序检查。
