## 旧版适配

1.21.1 使用可变 KeyboardInput，自动步行只写入当前方向和移动量，保留原对象供下一 tick 读取真实按键。手动移动优先，关闭模块后不残留自动按键。授权检查仍在动作入口与 tick 开头。

原生 1.21.1 没有矛物品；沿用原有 Via 兼容层，不宣称原生矛支持或本次已验证 Via 矛对战。MXS 同步共用追击逻辑，可用武器由服务端和兼容层决定。
