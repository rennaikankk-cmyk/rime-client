# 1.3.1-rc.18 — 界面重制与独立甲飞入口

- 甲飞换装统一由独立 ArmorFly 模块控制，移除鞘翅 Tricks 内重复开关；旧配置按原有效启用状态迁移，关闭的飞行配置不会自动开启换甲。项目预设保持关闭，使用时按需开启独立甲飞。
- 原生 shadcn 风格主菜单、ClickGUI、设置控件、HUD 编辑器和全部客户端 HUD。沿用 TargetHUD 的 Geist / 中文回退字体、深色卡片、圆角与细边框，无浏览器运行时。
- ClickGUI 改为分类、模块列表、设置详情三栏；支持全局搜索、键盘导航、精确数值输入、颜色输入、鼠标快捷键和设置恢复默认。
- HUD 支持拖拽、归一化位置保存、开关、重置和键盘微调。未渲染元素明确显示预览，小窗口工具栏可滚动。默认小卡片避让 TargetHUD 和快捷栏，手动位置保持用户设置。
- 通知卡片支持长文字收窄、整组移动和完整淡出；模块启停、死亡、爆图腾与物资提醒保留原事件来源。
- 修复从 HUD 编辑器返回 ClickGUI 时模块状态与设置事件订阅脱节的问题。
- 各 HUD 独立调整大小、背景/文字/强调颜色和背景不透明度，编辑器滚轮缩放、右键直达外观页；菜单大小同时作用于 ClickGUI 与主菜单，自动适配视口。
- 菜单和小卡片融入 InternalBeyond 的雾蓝与半透明层次，TargetHUD 默认设计保留。
- 文本、快捷键与 HUD 布局编辑时隔离 GuiMove 移动输入，避免编辑文字导致玩家移动。

本版不调整飞行速度、追击策略、攻击逻辑或授权校验。此文件记录本地候选内容，发布状态以发布记录为准。
