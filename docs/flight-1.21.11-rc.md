# 1.21.11 重锤追击候选版

基线：用户确认的本机 `homovore` 提交 `31c7b78`，在独立副本开发；候选版本 `1.3.1-rc.1`。原工作区未修改。旧 JAR 只用于静态对照，未执行。

## 本轮改动

- 重锤拉升会计算追上目标并完成下砸的总路程。目标平飞或斜上飞时，优先选择可完成的较低拉升高度；不可达时先追近。一次攻击过程中不会不断买回已经放弃的高度。
- 平稳飞行目标使用三维拦截预测；急转弯或加速时缩短预测，避免沿过时的方向追远。目标继续上升时，完成拉升的条件使用当前相对高度，避免永远追逐上移的顶点。
- 接近命中距离后匹配目标速度并收敛位置误差。在本地运动范围允许时保留收速请求；远处仍可沿拦截方向扩展速度。避免角点填充把拦截方向拉偏。
- 玩家移动完成后再检查一次真实攻击窗口。保留实际交互距离、视线、重锤下落条件、发包取消处理及服务端伤害确认。
- 甲飞每次移动前保证拥有的鞘翅在胸位，移动后返甲。滑翔标志尚未清除时仍换装，但不重复发送开始滑翔指令。手动换装、界面操作、停用及重锤俯冲交接继续遵循原有恢复规则。
- 新增独立 `AutoUse`：物品正则白名单、主手优先/副手兜底、附近敌人筛选、可选食物使用。只接管自己发起的持续使用，手动操作和追击武器控制优先。
- 修复首次启动配置缺失的错误日志、字符串下划线损坏、重复加载预设反向切换开关、启用时读到旧设置的问题；配置保存改为同目录临时文件替换。
- 固定 Loom 版本，补齐被忽略的保护资源，校验混淆后 GUI 覆写、枚举与授权检查，CI 只上传混淆包。

## 使用预设

1. 用 Java 21、Minecraft 1.21.11、对应 Fabric Loader/API；商业授权流程照旧。候选混淆包需要正常登录器授权。
2. 在游戏里先执行 `.configs save before-mace-rc` 保留当前配置。
3. 把仓库 `configs/mace-intercept/` 整个文件夹复制到实际游戏目录的 `guizhouware/configs/`，执行 `.configs load mace-intercept`。
4. 预设加载后这三个模块均关闭。准备可用鞘翅、烟花、重锤；快捷栏另留一格胸甲，胸甲格不要作为当前选中格。启用 `GuangxiElytraChase`，它会按设置接管飞行。
5. 按 WASD 会暂时让出追击控制。需要独立举盾或蓄矛时再启用 `AutoUse`。普通原版剑没有持续使用动作，白名单不会让它产生不存在的右键动作。
6. 同条件比较旧逻辑时，可关闭 `MaceAdaptive`、`MaceTerminal`。完整恢复原设置用 `.configs load before-mace-rc`。

这份预设只覆盖表列模块的部分设置，未列出的设置保持原值；好友与目标过滤沿用当前配置。它是测试起点，不是服务器通用参数保证。

## 验证边界

确定性几何测试中，同速预算的完整“拉升→下砸”路径：平飞样例 19→14 tick，斜上飞样例 19→13 tick。该模型不含真实网络、服务器插件及对手主动闪避，不能解释为实战提速比例。

状态测试覆盖延迟滑翔标志、重复 START、恢复与装备所有权；运动测试覆盖速度范围、障碍保护与近距收速。完整构建包含混淆与最终产物校验。

真实服务器命中率、拉回频率、甲飞持续速度仍须在实际延迟和服务器配置下对照。每 tick 换装仍可能产生两次装备交换；本轮没有宣称降低该频率或通过 Grim。上线前需完成同一最终 SHA256 的授权启动、GUI、Microsoft 21.0.7 与较新 JDK 的发行验收。
