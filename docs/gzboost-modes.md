# GZBoost 温和 / 激进档位

本版目标为 combat.9 / mc1211.9 / direct.14；新增档位承接上次发行。正式发布状态以官网和发布回执为准。

- Mode=Grim 时显示 GZBoost，总开关仍默认关闭。
- 开启 GZBoost 后紧接着显示 GZBoostMode：Gentle（温和）/ Aggressive（激进）。
- 默认 Aggressive；已有只有 GZBoost 的配置首次加载保留原激进行为。
- 档位是普通配置设置，保存后再次开关 GZBoost 会保留选择，不会强制改回激进。
- GZBoost 关闭或 Mode=NoAC 时隐藏档位，已保存的选择不影响普通控制。

温和档恢复 climb10 的沿轴拉升候选：运动俯仰 -86.25°，范围朝向交替 ±20°。
激进档保留当前发行参数：-89.25°、±72.5°。两档沿用连续的方向权重，
对角拉升均为 -89.25°、±45°；中间方向保持原算法。平飞、下降、烟花衔接、
纯垂直和协议回退规则相同。因此 Gentle 是拉升侧摆更小的方案，不是整体限速档。
空战的三参数 Intent 保持普通控制，不会因手动 GZBoost 档位而自动变更。

历史本地实测：温和沿轴上升约 146.84 格/秒、左右范围约 0.75 格；激进约
215.50 格/秒、左右约 1.91 格。来源为 climb10 原始服务端与客户端轨迹，
其中温和转头记录为 -86.25° / ±20°。这些历史结果不等于新增菜单在所有
服务器的速度保证，也不是重新进行了一轮联机测试。环境限制见 gzboost-climb.md。
