# 空战规避与珍珠落点预测（待发布）

针对规避状态保持、实际航向仍每 tick 重算的问题，新增短时世界坐标航向保持。敌方珍珠使用独立落点威胁评估，接入空战防御；不把它当作普通伤害弹丸，也不依赖 Trajectories 开启。未引入果蝇数据、权重、模型进程或额外运行依赖。

## 设置

GuangxiElytraChase 的 Defense 页（中文为“防御”）：

| 设置 | 默认值 | 行为 |
|---|---|---|
| EvadeCommitment | 开启 | 短时保持规避航向，障碍、新事件或危险升级可打断 |
| EvadeHoldTicks | 3 | 每次保持 1–6 tick；默认 150 ms（20 TPS） |
| EvadeRearm | 开启 | 保持结束后 2 tick 内，同一事件正常计算方向但不重新锁定；不忽略攻击 |
| PearlDefense | 开启 | 预测即将到达自己附近的敌方珍珠落点 |

上述防御遵守已有 AdaptiveCombat 与战斗模式门槛；FOLLOW 不新增自动交战。英文仍为默认语言，新增选项及说明支持中文切换。

## 实现边界

- 保持单位方向；速度上限与执行仍交给原飞行系统。规避通过 FlightVelocity 的方向优先标记让耦合巡航让出方向控制。无安全出口时请求刹车；地形路线覆盖时取消旧方向保持。
- 事件按会话、实体、武器类型、攻击开始时刻/下砸阶段区分。新紧急珍珠叠加已有武器威胁时也刷新事件，避免去重掩盖新危险。
- 保留重锤攻击窗口优先级、矛持有使用权。暂停、目标切换、传送纠正、死亡/换世界与停用清理保持状态。
- 珍珠在客户端线程预测，每 tick 最多计算 4 个候选、每个 12 tick；候选按相对接近程度排序。自己、好友、未知所有者及不满足目标规则的玩家均不触发强制规避。
- 落点与到达时自己的线性预测位置比较，区分持矛与普通近战范围。规避方向按全部有效珍珠中的最差距离余量评分，并兼顾当前紧迫武器威胁。
- ProjectilePrediction 为渲染与空战共用的世界适配层：包含本机玩家碰撞、世界边界、原版随年龄增长的实体碰撞裕量；水阻力只使用水标签。碰撞检测读取当前实体包围盒，未来转向、移动实体位置、网络延迟、传送门和气泡柱等特殊情况尚不能精确预测，落点估计并非必然结果。
- 现有异步 AerialDuelPredictor 的普通投射物列表保持原样；珍珠通过带所有者/到达时间语义的独立路径进入防御，避免使用普通弹丸的更新顺序。

连续拉起保留现有安全控制，待有抖动/速度损失证据再改。rusher、gzboost 推进数学和商业保护代码没有修改。

## 验证入口

`gradlew.bat --offline check` 包含新增 EvadeCommitmentTest、PearlLandingThreatTest，以及既有巡航、路由、武器和授权回归。

`tools/combat-probe/run-probe.ps1 -Name defense-world -WorldPath <测试存档> -Mode DEFENSE` 启动独立 Minecraft 1.21.11 集成服/客户端，验证原版珍珠轨迹、模块接线、巡航方向让权、无路刹车及清理。敌人由客户端注入，不代表真人对战效果。

武器损伤回归使用 SPEAR/MACE 模式和 `-RequireDamage true`；`-Adaptive true` 可开启自适应策略。场景参数、完成文件和日志参见 combat-probe 的 README。

沿用显式开启的 ClientDiagnostics：记录保持、重选、遇障、去重、航向反转计数和珍珠检测耗时，不新增网络上报或玩家标识日志。合成反转回放只能说明抑制抖动，不能推导命中率或胜率。
