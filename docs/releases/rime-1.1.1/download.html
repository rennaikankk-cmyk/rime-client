Rime 1.0

已发布Minecraft 1.21.11Minecraft 1.21.1

客户端和登录器对外名称改为 Rime，版本号为 1.0。界面、标题、聊天前缀和帮助改为 rime；旧的点号、gzw、guizhouware 前缀仍可输入，帮助里只显示 rime。水晶、锚、床和近战走同一条战斗热路径。

  • 自动水晶

    候选点的乐观伤害放到后台排序。精确伤害、自伤和放置仍在主线程做完才发包。主循环放成功后记下当前 tick，反应式扫描不会在同一 tick 再放一次。

  • TP 水晶

    不再每 tick 扫 200 格内的全部实体。铺好黑曜石后重置计时，避免同一 tick 反复丢黑曜石和水晶。旋转打开时，假移动对准点击点或水晶。

  • 活塞水晶

    乐观伤害盖不过当前最优时，不再做精确射线。同一阶段连续失败会结束这次流程，而不是一直等到超时。主手或副手已经拿着水晶时直接放。

  • 锚、床与挖掘

    锚先按距离丢掉爆距外的格子。床和 TP 床只遍历玩家。TP 床的假移动带上对准床的俯仰，放置时仍用床的朝向偏航。AutoMine 把脚下方块列表按 tick 缓存。

  • 副手与 KillAura

    图腾仍是默认。血量低于阈值时强制图腾。水晶、TP 水晶、活塞水晶、床、锚开着时，会在对应动作前把副手换成水晶、床或重生锚。KillAura 复用自动剑的距离、旋转和换武器；两者同时开时，这一拍只由 KillAura 出手。

  • 主菜单和其他模组

    其他模组加到标题画面上的文字按钮，会跟单人、多人和选项一起排进卡片网格，不再叠在品牌字上，也不会被塞进角落小图标。语言和无障碍仍留在右上角。

  • ClickGUI 打开掉帧

    默认紫色面板不再每帧调用原版全屏模糊，打开后只压暗世界。配置目录只在打开配置页时读一次。面板里的模块列表按搜索词缓存。

  • 设置说明

    每个设置项都有一句中文说明。紫色和蓝框面板把说明放在底部悬停提示里。现代卡片在设置行下面写一行小字。1.21.1 的界面在设置行下面写同一句，悬停时也显示。

  • 登录器

    窗口和品牌改为 Rime 1.0。本机标识还没读完或账号密码为空时，会直接说明原因，而不是没有反应。登录、安装和设备校验方式没有改。

    发行包继续带签名心跳、账号水印、混淆，以及按账号生成的文件清单校验和固定证书的授权连接。每份客户端内嵌独立水印与账号凭据，转售或共享将定位到购买账号并封禁。

AutoMaceDive=true（当前默认开启）。启用时需要 MACE 或 MXS 模式、AutoControlElytra=true，以及已开启且 Takeoff=true 的飞行模块。准备可用鞘翅和快捷栏中无绑定诅咒的胸甲。
空战威胁策略
ThreatMode=ALL_PLAYERS 为默认值。这是追击策略，不是对玩家是否使用外挂的检测结论；好友排除规则继续生效。

rc13 历史预设包：三份经对打验证的原版服重锤配置（vanilla-mace 系列）与手动耦合巡航。放入 guizhouware/configs/ 后用 .configs load <名字> 加载；预设只覆盖列出的设置，其余沿用当前配置。
云参数与导入导出
ClickGUI 顶部“云参数”进入独立页面，提供私有账号同步与会员公开预设，授权客户可上传公开模块设置。本地可用 .configs export <name|live> <path> 与 .configs import <name> <path> 传输 JSON；云端操作可用 .configs cloud private|public list|save|load|delete。公开预设仅含模块设置。
诊断与异步默认值
.diag start 60 开始本地采样，.diag export 保存报告。飞行 ParallelPlanning 默认开；锚 AsyncCompute 默认关，结果有效期默认 2 tick、捕获预算 4 ms。两者是独立设置。
服务器兼容性
飞行约束使用客户端预测，实际移动、命中和伤害由服务器判定。速度与 YCap 是设置值，不代表实测速度；不承诺 Grim／2b2t 通过率或零回弹。

自动诊断上传须知

适用版本：本须知适用于 1.3.1-rc.21-protection.1（rc21）起的新版客户端。使用含有效遥测凭据的客户端并进入游戏时，会自动向 Rime 服务上传诊断数据，用于排查运行问题、评估模块表现和改进版本。

新版不再提供上传 on/off 选择；旧 enabled=false 不再停用 rc21 自动上传。旧配置迁移时保留随机安装标识。

上传范围
客户端与游戏版本、相关模块及部分设置、延迟和 TPS 等运行指标，以及战斗、移动和飞行事件与摘要，包括速度、装备类型、攻击、受伤与图腾事件等诊断信息。
标识与账号关联
上传随机生成的安装标识和会话标识；服务器地址经哈希处理后上传，不发送明文地址。遥测凭据可与授权账号关联，这些数据不属于完全匿名数据。
不上传的内容
遥测不上传聊天内容、玩家姓名、玩家 UUID、绝对位置坐标或账号密码。随机诊断标识不使用玩家 UUID。
本地诊断报告
.diag 生成的详细性能报告保存在本地，不会自动上传。
查看接收状态
使用 .telemetry status 查看自动遥测状态与服务端接收结果。接收器确认仅表示 HTTP 2xx 响应，不代表独立核验落盘。

v1.3.1-rc.13 · 2026.09.19 · 耦合巡航双视角

  • 双视角（CruiseDualLook，默认开）

    拉升/俯冲段额外求解一个“盒视角”（拉升=平视，俯冲=自动求解对），并在本 tick 移动包之前直发一个同位置的追加转头包上报它；包络盒的第二视线由上一 tick 实际视角改为锚定盒视角。效果：运动视角可以很陡以获得强爬升，而水平速度的增长额度按平视计算——拉升段不再丢弃水平速度。每 tick 包序（重同步 → 盒视角包 → 移动包）与参考端一致。
