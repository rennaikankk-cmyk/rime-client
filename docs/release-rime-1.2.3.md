# Rime 1.2.3 · 战斗、HUD 与防护增量

沿用 rimeguard 3.3、P1c.2 HWID 租约与双下载通道；native DLL、密钥、池租约与旧客户端协议保持兼容，不触发租约轮换。

## 客户端

- 水晶、TP 水晶、床扫描缓存及候选改善，事件总线/HUD 开销优化，15 个实用缺失模块。
- HUD 布局往返恢复；独立杀戮目标、即时投掷物防御与共享近战冷却；NoSlow/NoFall NoAC，关闭 Rotate 的使用路径。
- 逐动作 guard 桥改为类型固定的 MethodHandle，缓存调用目标，授权结果仍每次读取；撤销与异常仍拒绝动作。

详细行为见 `combat-fps-opentroll-20261001.md`、`hud-aura-noac-20261001.md`。云南水晶源码尚未提供，本版未替换 Rusher。

## 防护与发行

- Guard 宽限采用单调时钟，补充到期、时钟回退/环绕、撤销和超大宽限参数检查。
- 生产密钥从 Java 子进程命令行移到显式受控环境；合并和壳仍要求两份密钥同时提供。
- 服务端兼容补丁只重键 required-native 模板，避免对新格式的旧启动器通道普通池错误重键；保留 native v1/v2、签名、水印和老登录/心跳路径。
- 修复壳离线重算游戏类栈帧造成 HUD 初始化 VerifyError：保留原帧，只给新控制流补帧；覆盖外部类合并、宽参数及入口循环的回归。启动错误记录限量原因类型和栈帧，省略异常消息。
- 完整构建、混淆、guard、合并、壳、VerifyMerge、生产签名双 JDK 启动通过后，才允许切换三处分发与 GitHub Release。
