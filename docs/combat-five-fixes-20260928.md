# 空战与渲染五项修复（2026-09-28）

本轮修复已于 2026-09-28 推送 main，并随 Rime 1.1.2 / Rimeguard 3.1 正式发布；回执见 docs/releases/rime-1.1.2/。保留此前的平地水晶底座、字体改动；没有改动 Rusher 逻辑或授权保护。

## 修复内容

1. **重锤**：收翼原先只接受快捷栏胸甲；找不到时保留滑翔，额外普攻会掩盖没有重击的问题。现在可使用主背包胸甲，也可将鞘翅收进空槽。自动下砸期间不抢先普攻；无法收翼时给出提示。换装使用原版容器交互，保留装备归还、手动干预、物品使用和会话边界检查，不伪造下落距离。
2. **矛**：地面目标的飞行路线维持离地空间，与武器瞄准分开。地面交战不再将平缓路线重塑成 GZ 陡升/俯冲，避免地形保护反复取消蓄力；内圈判定加入水平距离，撤离留足重新进攻空间。低空无动力或需要补烟花时，自动蓄力适时让出物品使用。
3. **TP 水晶**：新增 Render 页的 `RenderDamage`、`DamageColor`、`DamageScale`。文字和方框可独立开关；显示本次放置、底座连放或打碎的预估目标伤害，沿用真实爆炸计算。底座连放使用包含未来黑曜石遮挡的候选伤害，过期或切换会话后清除。
4. **TP 床**：渲染范围采用床脚、床头组成的两格区域和 9/16 高度，修复整格高框。四个方向均对照原版床形状验证。
5. **模块列表**：默认自动列出当前开启且未隐藏的模块，实时响应开关；旧手动名单保留为 `WATCHLIST` 模式。HUD 的计数、堆叠高度与实际显示来源一致。

## 实机验证方式

使用独立复制的测试世界，在真实 Minecraft 1.21.11 客户端与原版集成服运行实际模块，读取服务器生命变化和伤害来源。没有改动正在使用的游戏实例或原存档。

测试角色从平地起步，使用无附魔重锤/下界合金矛、鞘翅与烟花。目标是无 AI、无击退的固定僵尸，戴头盔防日晒，每次扣血后补满。AdaptiveCombat 关闭以单独检查武器动作；这些数据不等同真人 PvP 命中率，也不是联机延迟或反作弊验收。

重锤测试高度 28；主背包与空槽两条路径均验证服务器装备恢复。地面矛分别检查开启和关闭地形保护，以及甲飞组合。渲染测试调用真实模块渲染入口，固定快照用于视觉检查，不当作自动攻击成功证据。

原始日志、轨迹和截图保存在被忽略的 `tools/combat-probe/runs/` 与对应运行日志中；复现方式见 `tools/combat-probe/README.md`。
