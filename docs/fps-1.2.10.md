# Rime 1.2.10：战斗计算与界面整理

用户反馈空战／水晶开启后掉帧。基线为 381cad8（1.2.9）加同一批本地 ClickGUI 改动。

## 热路径修复

- 水晶自伤安全检查：任一预测位置已经超出自伤或保命限制，即可否决该候选，无需继续求整条路径的最大值。部分最大值不会写入精确伤害缓存，后续伤害平衡计算仍得到完整最大值。
- 完整自伤计算：用无遮挡伤害作为上界；某预测位置的上界不超过已算出的最大值时，跳过该位置的射线。保留原有预测路径、全部必要射线、爆炸地形规则及动作前重新检查。
- 飞行路径：对体积不超过 4096 的路径包围盒先检查是否完全无障碍；仅当所有区块已加载、未越世界边界且完全无碰撞时直接通过。被占据的包围盒继续原有每半格短段检查，避免斜线路径被整块包围盒误拒。
- 飞行地形快照：逐区块读取，跳过确认全空气的区段；仅在单次同步捕获内复用同一形状的 AABB 分解。上下文碰撞形状仍逐位置获取，未加载区块仍视作障碍，时间与大小上限保持。
- 授权检查点、战斗间隔、预测精度、攻击距离均保留；不通过限制前台 FPS 或关闭模块制造提升。

## 可复现验证

`tools/fps-probe` 独立 Fabric 测试模组在真实集成世界运行。每轮预热后记录 100 个 tick：每 tick 12 个水晶候选的安全与精确自伤计算、64 条飞行路径查询、一次地形快照。25 个数值预测位置固定；原地形含黑曜石地板与墙。VSync 关闭，原版 260 为无限帧；854×480、视距 4。测试模组不进入发行 Jar。

| 热路径（100 tick 合计） | 基线 | 优化第一轮 | 优化复验 |
| --- | ---: | ---: | ---: |
| 水晶计算 | 514.62 ms | 148.33 ms | 167.51 ms |
| 飞行路径查询 | 149.46 ms | 43.01 ms | 42.04 ms |
| 地形快照 | 47.05 ms | 28.12 ms | 21.91 ms |

诊断窗口包含预热尾段与测量段，共 200 tick：水晶射线从 5,400,000 降至 1,512,000（减少 72%）。三轮所有记录的伤害值与路径结果 SHA256 相同。额外 3,924 项实世界验证覆盖原版短段查询对照、旧快照对照、空中／靠墙场景及自伤提前否决后同轮精确缓存正确性。

这是固定数值工作负载，不是完整多人实战或胜率测试。顺序运行可能受 JIT、系统噪声影响；不将上述耗时下降直接换算成客户 FPS 涨幅。帧间隔与 GC 原始观测保留在 `docs/verification/1.2.10-candidate/`。本次未验证所有 1.1.x 版本的具体回归点。

同版包含 ClickGUI 网格、控件对齐、搜索输入与共享圆角网格修复，详见 `clickgui-refinement-20261002.md`。1.21.1 仍按需同步，保持现有版本。
