# 平地追击、遮挡接近和矿洞回退（2026-10-04）

基线为 Rime 1.2.13，`8cab789d402d9f25afd781b2605645d36244e5c0`。本轮继续保留 [空战循环调整](aerial-attack-cycle-20261004.md)，没有发布或同步 1.21.1。

## 行为变化

- 平地移动目标按实际接近速度、延迟和运动稳定性计算水平拦截点，最多提前 8 tick／4 格。停步或反向时不延用旧速度；预测被障碍挡住就逐步收短。攻击仍使用真实观察到的碰撞箱、原有距离和视线校验。
- 低顶盖下改用较低的接近高度，不再要求取得不存在的落锤空间。重锤开启 `MaceUseExtraAttack` 时，允许冷却完成后的普通攻击；没有落差时不能把普通攻击称为高伤害重击。判定只看方块，不会把附近实体当成屋顶。
- 目标被击退到门外、自己还在屋檐下时继续完成低位接近。实际顶盖消失后最多保留 40 tick 的近距离地面策略，避免立即在屋檐边切换爬升；目标升空、变更目标或高度／距离不合适会解除。
- 低顶盖落地后，`TerrainGuard` 和 `CaveEscape` 同时开启时允许普通步行接近，不反复跳起尝试滑翔。每段检查站立碰撞箱、已加载区块、世界边界、液体和脚下支撑；不主动跳坑、穿墙或破坏方块。输入只替换当 tick，手动方向、跳跃、潜行、界面和其他输入所有者优先。
- 低顶盖寻路改用方块中心对齐的 1 格网格，保留 256 节点上限；开阔处仍用 2 格网格。同步和异步路径到达转角时，只有下一段完整可通行才提前推进，避免擦墙切角。
- `CaveEscape` 默认开启：记住最多 96 个来路点，持续受阻 12 tick 后暂停追击／攻击并沿来路回退。每一段都重新检查碰撞，回退请求限制为每 tick 最多 0.9 格；回退期间不追加救援烟花。位置跳变、切换会话、禁用及回弹会清除历史。
- 路径记录会保留落在两次距离采样之间的转角，避免只剩死胡同最后一段。落地后使用独立站立空间和地面支撑检查投影来路；可平飞或向上通过都失败时，恢复方向再考虑经完整轨迹检查的下降通道。

新增输入动作仍有最终授权检查；没有修改授权、防护资源或发行流程。

## 真实服务端功能诊断

本机 Paper 1.21.11 build 132、Grim 2.3.73、PacketEvents 2.14.0、ViaVersion／ViaBackwards 5.12.0；客户端 ViaFabricPlus 4.4.15 选择协议 765。攻击者开启空战、甲飞和 GZBoost Aggressive；靶子关闭空战／飞行／甲飞，保留图腾。靶子静止或用真实移动输入跑动，每 60 tick 换向。双方配置由既有夹具核对，运行 class 冻结并在结束时校验哈希。

**这是无还击靶子的功能诊断，不是新旧客户端 PvP 对照，更不是胜率。**客户端窗口为诊断主动限帧 60，没有用这些数据证明 FPS 优化。期间有一次短时回归构建，因此不做精细性能或 DPS 比较。

每次掉血按服务端来源归属筛选，排除摔落和撞墙；吸收、图腾、同期回血与溢出伤害会影响数值，因此这些是观察到的血量下降，不是武器原始伤害。原始失败轮次、日志与汇总均保留。

最后的“不对齐转角来路保留”修正发生在 D 轮运行 class 冻结后，通过独立窄道回退测试和完整回归验证；没有冒称该修正也经过矿洞实机测试。

## 矿洞验证与边界

自动测试覆盖两次连续窄道转角、偏离网格中心的入口、提前推进路径点、下降通道、96 点上限、新墙堵住旧路、位置跳变、路径时钟倒退、落地后的站立空间拒绝，以及不对齐的来路转角。步行测试检查不同朝向下的移动方向、手动接管、阻塞时停止、无效方向和到点停止。

矿洞功能属于**有来路、仍有可通行空间时的回退**。全封闭、没有有效历史、入口后来被封、站立空间不足或落地路线有高差／断崖时，会停止而不是强行穿过。平层步行不会自动挖掘、搭方块或规划台阶跳跃。复杂天然矿洞、低 TPS 与高延迟环境仍需进一步实机验证。

完整验证命令及结果由配套 JSON 记录；测试结束后恢复生产构建资源并检查开发开关关闭。未打发行包、未推送、未发布。
