# DEFAULT 水晶平地底座漏扫修复

此前底座候选从目标脚下低一格向下扫描，实心平地中的候选全部是不可替换方块，目标脚部同高的空气层没有被检查。因此附近没有现成黑曜石时，即使能在地面上放底座，也会返回空结果。

DEFAULT 现在在原有较低层候选均无结果后，增加目标脚部同高的一层搜索。仍使用现有放置和攻击距离、方块可替换性、实体碰撞、挖掘检测、真实地形和拟放底座遮挡、目标伤害门槛、自伤及收益检查。Rusher 的扫描层与顺序保持不变。

实机回归通过独立开发测试模组、原版 1.21.11 集成服以及复制的存档完成：

- `flat-base-before`：旧代码在双方同高、相距 6 格的实心草地场景复现无底座候选。
- `flat-base-after`：15 项检查通过；底座选中 `(4, 101, 0)`，服务器确认黑曜石，并完成放晶、攻击及目标扣血。
- 本例目标伤害预测 `19.118443`，服务器实际扣血 `19.11847`；提高底座伤害门槛或缩短放置距离仍拒绝候选。
- 夹具显式提供服务器僵尸目标缓存，驱动使用创造模式和抗性 V；不等同完整玩家自动寻敌或真人对战。没有降低生产安全设置。

复现命令见 `tools/crystal-probe/README.md` 的 `-FlatBase` 模式。原始日志和前后结果保存在仓库同级 `crystal-v2-lab/flat-base-before*` 与 `flat-base-after*`。

本修复已随 Rime 1.1.2 / Rimeguard 3.1 发布至官网和登录器源，并推送 main。

最终验证：生产配置下 85 个客户端回归任务全部通过（check）；代码空白检查通过。
