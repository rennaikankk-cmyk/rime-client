# 耦合巡航诊断补丁

`coupled-telemetry.patch` 面向 rc.5 飞行摘要接收器及其测试/管理页，包含四个文件的差异：`telemetry_service.py`、`test_telemetry_service.py`、`admin.html`、新增客户端生成的 `coupled_summary_fixture.ndjson`。

补丁使用平铺的审查目录布局，并不代表生产服务器上的目录布局。部署时先比对生产文件与补丁上下文，保留生产独立变更；不要用审查目录的完整旧副本覆盖生产服务。Windows 基线采用 CRLF，应用补丁后的内容已按统一换行比对，四个文件一致。

兼容性：旧客户端不带 `config.coupled` 仍可上传；新扩展一旦存在，11 个字段全部必填，拒绝未知字段、错误类型和越界值。管理页在飞行摘要中标明耦合巡航/脉动及总速帽。客户端每 tick 对比完整配置，切换开关或参数不会混窗。

验收：Python 3.12 + Flask 的 24 项接收器测试通过，包括原 23 项、客户端真实 renderer 生成的扩展 fixture、逐键删除和非法值、导出保留；管理页摘要函数对真实 fixture、历史记录和缺字段记录通过，未产生 NaN/undefined。

发布顺序：先验证并部署接收器与管理页，再发布 rc.11 客户端。原接收器会拒绝开启巡航后的新字段；客户端已有 400 降级会停发该会话的飞行摘要。这份补丁尚未部署。
